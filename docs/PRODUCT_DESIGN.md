# Product Design — Adem Portfolio

## Vision

Adem Portfolio présente le travail d’un frontend engineer à travers une expérience éditoriale et conversationnelle. Le site doit prouver la qualité d’exécution avant même que le visiteur ouvre une étude de cas.

## Core features

### Phase 1 — Foundation

- Portfolio responsive en light et dark mode.
- Hero conversationnelle avec deux assets 3D dédiés au thème.
- Pages projets, veille, à propos et contact.
- Collection de liens démonstrative.
- Panneau d’administration démonstratif.
- SEO, navigation clavier et page 404.

### Phase 2 — Content

- Études de cas détaillées alimentées par un CMS.
- Formulaire email connecté et protégé contre le spam.
- Articles de veille individuels.
- Métadonnées sociales par projet.

### Phase 3 — Polish

- Réponses IA basées sur le contenu du portfolio.
- Analytics respectueux de la vie privée.
- Internationalisation français/anglais.

## Non-goals for v1

- Aucun CRUD ni authentification admin.
- Aucune base de données.
- Aucun agent IA connecté à une API payante.
- Aucun faux formulaire transmis silencieusement.

## Key UX decisions

- Dark mode par défaut avec préférence persistée.
- Server Components par défaut, Client Components limités aux interactions.
- Un seul accent violet/bleu et une hiérarchie typographique forte.
